# 学習アプリ実装仕様 v1

2026-09-07。合意済みの方針を具体化した初版。ローカル専用。

## 提供物と責務

学習用シェル、18課題（基礎・中級・ナイトメア各6）、完成済みの独立リファレンスデモ、編集可能なタスク画面の枠、Expressの実行環境、テスト環境を提供する。タスクCRUDの完成解答と課題の完成テストは提供しない。

## 画面

左に難易度と課題一覧、中央に要件・4段階の学習手順・テスト観点、右に学習者が編集するタスク画面を配置。狭い画面では縦に並ぶ。関連リファレンスは課題内のトグルで開閉し、課題を移動したら閉じる。状態は保存しない。

課題は「要件 → 実装 → UI確認 → テスト」の順に手動で記録する。前工程が完了するまで後工程をチェックできない。前工程を取り消すと後工程も取り消す。テスト完了は自己申告であり、自動採点と表示しない。各課題の全工程完了を経て次へ進む。課題一覧の閲覧は制限しない。

進捗は当ブラウザのlocalStorageに保存する。不正な保存値を無視し、保存不能時も学習を継続できる。難易度は基礎を一巡→中級→ナイトメアの順で案内する。

## 題材

追加・一覧・編集・削除、完了切替、検索・絞り込み・並替、期限・優先度、API保存取得と通信状態。課題の受入条件は curriculum.md および画面の教材データを参照。

## 実装箇所

- src/exercises/TaskWorkspace.tsx: 学習者が編集するUI。初期は空の枠と未実装表示。
- server/exercises.ts: 学習者が編集するAPI。初期は501を返す。
- src/components/ReferenceDemo.tsx, server/reference.ts: 完成済みデモ。課題データと独立。
- src/data/curriculum.ts: 課題、要件、確認方法、テスト観点。

API課題の基礎ではメモリ保存から始め、再起動で消えることを明示する。永続化は発展として追加可能。初期の学習用土台には保存処理を実装しない。ブラウザ進捗とタスクデータを混同しない。

## テストと受入条件

Vitest + Testing Libraryで教材UIと進捗制御、VitestでAPI、Playwrightで実ブラウザの操作を検証。学習者のテスト置場は src/exercises/ と e2e/exercises/。提供テストは教材基盤に限定し、タスク機能の実装後に学習者がテストを追記する。

- 初期リファレンスが閉じ、キーボードでも開閉できる。
- 各工程は順序を守り、取り消しは後続に伝播する。
- 課題変更後も進捗が保たれ、リファレンスは閉じる。
- デモ操作によって結果が変わる。APIデモは実際のExpress応答を示す。
- タスク機能は未実装と明示され、デモの成功を課題完了と判定しない。
- build・lint・基盤テスト・ブラウザテストに合格する。

## 開発フロー

仕様書 → 実装 → テスト → 独立レビュー → 修正と再検証 → Notion「学習アプリ開発」に判断・要点・結果を記録。外部公開はしない。
