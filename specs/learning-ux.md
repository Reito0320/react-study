# 学習用UIとリセット方針

- 全4工程を完了した課題に「✓ 完了」をサイドバーで表示。保存済み進捗にも適用し、工程を取り消すと消える。チャプター0は「実演を確認した」の自己申告を別IDで保存し、18課題の件数には含めない。
- チャプター1の実演ガイドは取り除く。タスク実装は維持し、以前こちらが追加した学習用解答をTODOへ戻す。再開時に学習者が記述済みの3件は保持する。チャプター0の実演と基盤テストは維持。
- 学習者はTypeScriptの状態・イベント・API・テストを実装する。CSSは学習基盤が担当。意味的なHTMLへの既定スタイルを提供し、専用コンポーネント経由のイベント転送は要求しない。
- 参考資料の外部リンクはtarget=_blank、rel=noopener noreferrer。ページ内移動は同じ画面。
- 過去のチャプター1実演記録はdocs/archiveに退避し、現行教材から誘導しない。
