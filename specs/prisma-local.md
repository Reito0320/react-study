# ローカルPostgreSQL・Prisma教材

## 対象と学習順序

自分のPCで個人学習する人が利用者。DB未導入でも画面の手順から準備でき、既に接続できる人は準備をスキップできる。
基礎7でDB準備 → Prismaチュートリアル → 基礎8でタスクAPIの永続化 → 中級7でモックテストを学ぶ。基本18章と合わせて21章。既存のIDは維持する。

## 提供する構成

- .env.example：ユーザー・パスワード・ポートを自分の環境に合わせる例。
- db:apply：提供済みマイグレーションを適用する。db:migrateは後のスキーマ変更に使う。
- Prisma 7とpgアダプター、独立したPracticeTaskの追加・一覧サービス。
- db:check：確認用1件を作成・再取得し、そのIDだけ削除する。
- db:demo：データを残して保存・一覧取得を確認する。
- モック参考例3件と、一覧取得の学習用TODO2件。ローカルURL検証2件も提供。
- 学習画面・テスト結果パネル・スキーマ変更時の結果無効化に対応。

## 検証と制限

build・lint・関連テストで確認。今回は教材と設定の整理で、利用者の既存DBへの接続設定変更や実DB作成は行わない。具体的なユーザー・パスワード・ポートは利用者の既存環境に合わせる。
Prisma CLIの間接依存には先のnpm auditでhigh 4件が報告されており、強制的な旧版への変更は適用していない。

詳細手順はdocs/prisma-local.md。
