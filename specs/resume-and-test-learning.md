# 再開・テスト同期・任意課題（2026-09-08）

- 選択章をlocalStorageに保存。再読み込み時に復元し、不明なIDや保存不可時はチャプター0から始める。
- テスト名の正本はReact/Expressの学習用テストファイル。TypeScriptの構文解析で静的なdescribeとit/test（todo/skip含む）からIDとタイトルを抽出。APIはテストを実行しない。
- 3秒ごとの結果取得で項目を同期。実行前もTODOの項目を読み取れる。構文不正・重複IDはエラー。動的タイトルとeach生成は対象外として文書化。
- 古い実行結果は引き続きソースハッシュで無効化。UIの表示名更新と成功判定を分離。
- 任意の検出力課題を右側の初期閉トグルへ追加。基礎は章別の不具合例、それ以降は自分で要件を選ぶ。元コード保存→正常系確認→一時的な不具合→失敗理由確認→復元と再実行。自動改変や必須チェックは追加しない。
- 既存のカード選択stateが未使用で型チェックを妨げていたためaria-currentへ反映。学習者のテスト本文は変更しない。
